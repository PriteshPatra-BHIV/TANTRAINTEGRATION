## 1. Contract Schema

DGIC output is locked to exactly these 7 fields — no more, no less:

| Field | Type | Constraint |
|-------|------|------------|
| `execution_id` | string | UUID v4 |
| `execution_hash` | string | SHA-256 hex (64 chars) |
| `decision` | string | `ALLOW` / `DENY` / `ESCALATE` |
| `epistemic_state` | string | non-empty |
| `confidence` | float | 0.0 – 1.0 |
| `reason_trace` | list | non-empty |
| `collapse_trigger` | string | non-empty |

Any missing field → `INVALID`. Any extra field → `INVALID`. No tolerance.

---

## 2. Hash Logic

```
execution_hash = SHA256(
    canonical_json({all fields except execution_hash}, sort_keys=True)
)
```

- `execution_id` is part of the hashed payload — binding identity to content
- Canonical JSON uses `sort_keys=True, separators=(",", ":")` — deterministic always
- RAJYA recomputes this hash independently and compares — any mutation is caught

Implemented in: `dgic_contract_validator._recompute_hash()`

---

## 3. Validation Flow

```
RAJYA receives DGIC payload
        │
        ▼
dgic_contract_validator.validate(payload)
        │
        ├─ payload is dict?              → INVALID if not
        ├─ missing fields?               → INVALID with field list
        ├─ extra fields?                 → INVALID with field list
        ├─ correct types?                → INVALID with field + type
        ├─ decision in {ALLOW,DENY,ESCALATE}? → INVALID if not
        ├─ 0.0 ≤ confidence ≤ 1.0?      → INVALID if not
        ├─ reason_trace non-empty?       → INVALID if empty
        └─ recompute hash == stored hash? → INVALID if mismatch
                │
                ▼
        {"status": "VALID", "execution_id": "..."}
```

## 4. Failure Cases

All tested in `dgic_contract_validator.py` (16/16 pass) and logged in `proof_failure_cases.json`:

| Case | Mutation | Result |
|------|----------|--------|
| Missing field | `collapse_trigger` deleted | INVALID — Missing fields |
| Extra field | `injected` key added | INVALID — Extra fields not allowed |
| Hash tampering | `decision` mutated, hash not updated | INVALID — tamper detected |
| execution_id mismatch | `execution_id` swapped | INVALID — tamper detected |
| Invalid decision | `decision = "MAYBE"` | INVALID — decision must be one of |
| Confidence out of range | `confidence = 1.5` | INVALID — confidence must be 0.0–1.0 |
| Empty reason_trace | `reason_trace = []` | INVALID — reason_trace cannot be empty |
